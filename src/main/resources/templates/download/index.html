타닥 라이브 앱은 지금 타는 방송과 다시 보기를 한눈에 보여 주고, 녹화방송은 앱 안에서 바로 재생합니다. 라이브 시청·로그인·댓글·장작 넣기는 앱 안 창에서 이 사이트 화면을 열어 씁니다.

Windows용 받기

macOS

macOS 11 이상 · Apple Silicon·Intel 겸용 · 디스크 이미지 .dmg · 약 9MB

macOS용 받기

받기 버튼은 항상 최신 버전을 내려받습니다. 모든 버전·변경 내역

macOS에서 처음 열기

  1. 받은 .dmg 를 열고 Tadak Live 를 응용 프로그램(Applications) 폴더로 끌어 넣습니다.
  2. 앱을 열면 "Apple은 'Tadak Live'에 악성 코드가 없음을 확인할 수 없습니다"(Apple could not verify…) 경고가 뜹니다. 완료를 누릅니다. 휴지통으로 옮기지 마세요.
  3. 시스템 설정 → 개인정보 보호 및 보안을 열고 아래쪽의 그래도 열기를 누릅니다.
  4. 다시 뜨는 창에서 그래도 열기를 누르고 Mac 암호(또는 Touch ID)로 확인합니다. 다음부터는 그냥 열립니다.

macOS 15부터는 Control-클릭 → 열기로는 넘어가지 않습니다. 그래도 열기 버튼이 보이지 않으면 터미널에서 아래 명령을 실행한 뒤 다시 여세요.

xattr -dr com.apple.quarantine "/Applications/Tadak Live.app"

Windows에서 처음 실행

  1. 받은 Tadak-Live-windows-x64-setup.exe 를 실행합니다.
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보를 누른 뒤 실행을 누릅니다.
  3. 설치 마법사를 따라 설치합니다. 화면을 그리는 Microsoft Edge WebView2가 없으면 설치 중에 자동으로 받습니다.

왜 경고가 뜨나요?

타닥 라이브는 개인 프로젝트라 유료 코드 서명 인증서를 쓰지 않았습니다. 그래서 운영체제가 만든 사람을 확인하지 못해 경고를 띄웁니다. 설치 파일은 공개된 소스 코드로 이 저장소의 GitHub Actions가 직접 빌드해 Release에 올린 것입니다. Release 목록에서 버전마다 어떤 커밋으로 만들었는지 볼 수 있습니다.

휴대폰에서는

iPhone·Android 앱은 따로 없습니다. 휴대폰 브라우저(Safari, Chrome)로 이 사이트를 그대로 쓰면 됩니다. 라이브 송출(불 피우기)도 휴대폰 브라우저에서 합니다.
