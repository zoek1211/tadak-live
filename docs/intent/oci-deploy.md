# 의도: OCI 무료 VM 배포와 데스크톱 클라이언트

2026-11-22 인터뷰로 확정한 내용이다. 구현 계획과 스펙은 이 문서를 바탕으로 따로 만든다.

## 결과물

타닥 라이브(`zoek1211/tadak-live`)를 OCI Always Free VM 한 대에 HTTPS로 띄운다. `main`에 푸시하면 백엔드·웹·다운로드 페이지·Windows/macOS 데스크톱 앱이 GitHub Actions로 자동 빌드·배포된다.

## 사용자와 클라이언트

- **웹:** 지금처럼 누구나 방송 시청·송출·댓글·후원을 한다. iPhone은 웹(Safari)으로 쓴다.
- **데스크톱 앱(B 방식: 자체 화면):** 배포한 백엔드의 방송 목록을 **API로** 불러와 앱 화면에 그린다. 녹화방송은 앱 안 플레이어로 재생한다. 라이브 시청(WebRTC)·로그인·댓글·후원은 앱에서 웹 화면을 열어 쓴다.
  - 웹을 그대로 감싼 앱(A 방식)은 택하지 않았다. 요구사항 "클라이언트에서 배포한 백엔드의 방송 목록을 조회하고 재생"을 정확히 만족하고, 같은 API를 나중에 다른 클라이언트도 쓰게 하기 위해서다.
  - 지원 대상: Windows x64, macOS Apple Silicon·Intel. 구현 언어·패키징 도구는 자유(후보: Tauri).

## 서버(VM)

- 홈 리전 가용성과 계정의 남은 무료 한도를 먼저 확인한다.
- 1순위: `VM.Standard.A1.Flex` 2 OCPU·12GB(ARM64). 계정 안 다른 A1 인스턴스가 무료 할당량을 쓰지 않을 때의 기준이다.
- 재고·리전 제한이 있으면 무료 대안(예: `VM.Standard.E2.1.Micro`)으로 만들고 선택 이유를 README에 남긴다.
- VM 한 대에서 단독 실행으로 배포한다(5단계 오토스케일 구성은 쓰지 않음).

## 주소·DNS·TLS

- **1단계(지금):** `<공인IP>.sslip.io` 임시 주소에 Let's Encrypt HTTPS. 백엔드와 다운로드 페이지를 HTTPS로 제공한다.
- **2단계(도메인 확보 후):** `zoek.im` 사용. OCI DNS 영역을 만들고 GoDaddy에서 네임서버(NS)를 OCI로 넘긴 뒤 인증서를 새 주소로 다시 받는다.
- **도메인 현재 상태(2026-11-22 확인):** `zoek.im` 은 .im 등록소 WHOIS에서 "not found", 공개 DNS에 NS 없음, GoDaddy 계정의 도메인 목록도 비어 있다. 구매가 끝나지 않은 것으로 보인다. 사용자가 GoDaddy 주문 내역·결제 메일·다른 계정 여부를 확인하고, 필요하면 다시 결제한다.
- README에 적을 것: 도메인 등록 여부, 최초 등록 비용과 갱신 비용(실제 결제 금액), 공개 주소, DNS·TLS 구성 방법.

## 백엔드 변경

- 기존 방송·계정·댓글·후원 기능을 유지한다.
- 배포용 실행 설정과 상태 확인 경로를 추가한다.
- 데스크톱 앱용 방송 목록 JSON API를 추가한다(예: `GET /api/broadcasts`).
- 서비스 주소와 비밀 값(DB 비밀번호, 토스 키 등)은 GitHub Secrets와 VM의 환경 설정으로만 관리하고 커밋하지 않는다.

## 다운로드 페이지

OS별 파일 링크, 지원 아키텍처, 설치·실행 방법을 보여 준다. 서명하지 않은 앱이라 뜨는 macOS Gatekeeper·Windows SmartScreen 경고의 우회 방법도 안내한다.

## 사용자가 직접 하는 일

- OCI 로그인·동의, GitHub 동의, 토스 테스트 키 입력(채팅에 붙여 넣지 않고 직접 입력)
- 도메인 결제, GoDaddy 네임서버 변경

나머지 단계는 에이전트가 진행한다.

## 제약

- Always Free 범위만 쓴다. 도메인 비용 외에는 비용이 들지 않는다.
- VM 한 대.

## 하지 않는 것

- iOS 앱(Apple Developer 유료 계정이 필요해 "무료·자동 배포"와 맞지 않음)
- 데스크톱 앱 안에 로그인·댓글·후원·송출을 다시 만드는 것
- 앱 코드 서명(Apple·Windows 모두 유료)
- 여러 VM, 오토스케일
- 도메인 구매 자체
